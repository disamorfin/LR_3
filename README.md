# Центр мониторинга космического мусора

## Этап 1. Описание проекта

Проект представляет собой информационную систему для учёта и мониторинга космических объектов и фрагментов на орбите.

Система должна хранить информацию о космических объектах, результатах наблюдений и опасных сближениях.

## Основные функции

- регистрация космических объектов;
- добавление результатов наблюдений;
- изменение статуса объекта;
- фиксация опасных сближений;
- учёт средств наблюдения;
- формирование отчётов.

## Пользователи системы

- сотрудник центра мониторинга;
- руководитель центра.

## Основные сущности

- Космический объект;
- Наблюдение;
- Средство наблюдения;
- Опасное сближение;
- Отчёт.

## Архитектура

Система будет разрабатываться с использованием архитектуры MVC:

- Model;
- View;
- Controller.

## Текущий этап

На данный момент выполняется анализ предметной области и проектирование системы.

На втором этапе были построены модели проектируемой системы.

---

## Этап 3 — Программная реализация

На третьем этапе было разработано десктопное приложение на языке Python.

Для пользовательского интерфейса используется Tkinter, для хранения данных — SQLite.

Приложение построено с использованием архитектуры MVC:

- Model — классы и бизнес-логика системы;
- View — графический интерфейс;
- Controller — взаимодействие между интерфейсом, моделями и базой данных.

В системе реализованы следующие возможности:

- добавление космических объектов;
- просмотр списка объектов;
- удаление объектов;
- изменение статуса объекта на «утерян»;
- повторное обнаружение объекта;
- хранение координат и скоростей движения объектов;
- автоматический расчёт сближений между объектами;
- определение минимального расстояния;
- определение опасных сближений;
- формирование отчёта.

Расчёт сближений выполняется на основе координат объекта X, Y, Z и его скорости VX, VY, VZ.
