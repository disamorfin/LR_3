# Центр мониторинга космического мусора

## Описание проекта

Проект представляет собой информационную систему для учёта и мониторинга космических объектов и фрагментов на орбите.

Система должна хранить информацию о космических объектах, результатах наблюдений и опасных сближениях.

## Основные функции

- регистрация космических объектов;
- добавление результатов наблюдений;
- изменение статуса объекта;
- фиксация опасных сближений;
- учёт средств наблюдения;
- формирование отчётов.

## Пользователи системы

- сотрудник центра мониторинга;
- руководитель центра.

## Основные сущности

- Космический объект;
- Наблюдение;
- Средство наблюдения;
- Опасное сближение;
- Отчёт.

## Архитектура

Система будет разрабатываться с использованием архитектуры MVC:

- Model;
- View;
- Controller.

## Текущий этап

На данный момент выполняется анализ предметной области и проектирование системы.
